# Лабораторная работа 1 — качество и дрейф данных

Исследование влияния качества текста и временного сдвига данных на показатели мониторинга жалоб в отзывах о товарах.

## Содержимое

- [`lab1_data_quality_drift_product_metrics_T4.ipynb`](lab1_data_quality_drift_product_metrics_T4.ipynb) — выполненный ноутбук с кодом, таблицами и графиками. Из сохранённых выводов удалена таблица с фрагментами исходных отзывов; при повторном запуске она строится в Colab.
- `report.docx` — отчёт Word с постановкой, обзором литературы, протоколом, метриками и выводами.
- [Ноутбук в Google Colab](https://colab.research.google.com/drive/1Q-Pbqna9H0yZ7lUCJM18KFJ3TRyzpzvC?usp=sharing).

Используется категория `All_Beauty` из [Amazon Reviews 2023](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023), ревизия `749931181c9cdd70bfa6408d8fe8b4ddd6107248`. Метка тональности построена из рейтинга: 1–2 звезды — `NEGATIVE`, 4–5 — `POSITIVE`; 3 звезды исключены. Это прокси-метка, а не ручная разметка тональности.

## Ключевые результаты

На общем test из 120 отзывов максимальный macro-F1 составил **0,967** для Qwen2.5-1.5B few-shot. Для позднего среза по validation была выбрана SmolLM2-1.7B zero-shot; её macro-F1 на test — **0,875**. На 240 поздних отзывах повреждение 30 % текстов снизило macro-F1 этой модели с **0,912 до 0,831**, а число пропущенных жалоб выросло с **29,2 до 100,0 на 1000 отзывов**.

На validation объёмом 60 отзывов критерии выбора дали ничью между SmolLM2 zero-shot и Qwen2.5-1.5B few-shot. Поэтому выбор модели не следует считать устойчивым. Подробные ограничения и анализ ошибок приведены в отчёте.

## Использование данных

Авторы набора (https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023/discussions/1) исходным текстам отзывов и предоставляют данные прежде всего для исследований. Исходные тексты и parquet файл в репозиторий не включены.
